Ask

Ask the resume anything.

There is no server behind this. A small quantized language model is downloaded into your browser, compiled to WebGPU shaders, and run on your own graphics card. Nothing you type leaves this machine, and once it has loaded you can pull the network cable and it will keep answering.

A model this size gets details wrong. For anything that matters, the resume and LinkedIn are what to trust, and the contact button on the homepage reaches a person. It only knows what is on this site: it has no access to anything else, and it cannot look anything up. Built on WebLLM.

How this works, and what it can drive

Where the model runs

The weights stream from a CDN once, about 1.4 GB, and are kept in this browser's cache, so every later visit starts in seconds. They are compiled to WebGPU shaders and executed on your GPU. There is no API key here and no request to any server: the network is used to fetch the model and for nothing else.

The model itself is held by a service worker rather than by the page, so it survives you navigating between the pages of this site. Load it here and the assistant panel on the simulators is already warm when you get there.

Two kinds of message

A question goes to the model, which answers from a profile written into the page. Anything unrelated to Mark or to this site is refused before it reaches the GPU, by a check that costs nothing and cannot be talked out of it.

A command never touches the model at all. “Load the Hoeken and run it” is matched against a fixed grammar and executed exactly, so the simulator can never be driven by a model's guess. On this page a command becomes a link into the right tool; on the tool pages the same panel presses the buttons.
